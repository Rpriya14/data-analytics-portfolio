# Data Analytics Portfolio

## Overview
This repository contains end-to-end Data Analytics projects using SQL, Excel, Power BI, and Python.  
The projects demonstrate skills in data cleaning, data analysis, visualization, and business insights generation.

---

## Tools & Technologies
- SQL (Data querying, joins, aggregation, window functions)
- Excel (Data cleaning, formulas, pivot tables, dashboards)
- Power BI (Data visualization, DAX, Power Query, dashboards)
- Python (Pandas, Matplotlib, EDA, data cleaning)
